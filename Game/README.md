# Game

Godot 4.x C# project. This is the in-game client.

Subfolders:
- `Assets/`     - imported textures, audio, materials, models
- `Prefabs/`    - reusable scene prefabs (buildings, trees, road segments, vehicles)
- `Scripts/`    - C# gameplay scripts (car controller, chunk manager, etc.)
- `World/`      - generated/saved world data (chunks, save files)

The actual Godot project file (`project.godot`) and `.csproj` will be added
in Phase 1 when the engine project is created.
